# Contributing

OpenCanvas is plain HTML, CSS and JavaScript. Edit a file, refresh the page.

1. Fork and clone
2. Serve the folder with any static server
3. Keep everything on the global `OC` namespace and keep scripts in the order listed in `index.html`
4. UI text goes through `T()` so it can be translated. Keep copy short and skip descriptions unless they are needed
5. Open a pull request

Community apps and templates go in the registry repo, not here.
